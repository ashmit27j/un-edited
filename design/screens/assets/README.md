# Stamp and cursor SVGs

Thirteen screens use these 16 SVGs (stamps and web cursors). On the canvas they were stored as uploaded assets, which couldn't be exported with the screen files, so **the SVG files themselves aren't in this folder yet.** The screens already point to the names below, so they'll show up once the files are added. Until then those images show as broken (alt text only).

To fill them in, either:

- download each stamp from the **Stamps** board on the canvas (https://claude.ai/artifact/KBgcFxZShLJtR21cxHsr67) and save it here under the name below, or
- ask Claude Code to redraw them from the spec in `docs/current-config.md` §2 (this makes new versions, not copies).

`manifest.json` maps each file name to its original canvas asset id.

| File | What |
|---|---|
| stamp-brand-paper.svg / -capped | Brand stamp, oxblood |
| stamp-brand-ink.svg / -capped | Brand stamp, coral |
| stamp-published-paper.svg / -capped | As published stamp, oxblood |
| stamp-published-ink.svg / -capped | As published stamp, coral |
| stamp-free-paper.svg / -capped | Free stamp, oxblood |
| stamp-free-ink.svg / -capped | Free stamp, coral |
| cursor-pointer-paper.svg / -ink | Web pointer cursor, 32px |
| cursor-readmore-paper.svg / -ink | Web Read more stamp cursor, 64px |
