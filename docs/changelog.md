# Changelog

Newest first. One line per change: date — what changed — why (if known). Update `current-config.md` alongside.

- 2026-10-09 — Fixed Vercel production returning 404 on every page. Cause: the Git integration (auto-linked by `vercel deploy --yes`) built each push from the repo root, where `dist/` is gitignored and there was no build command, so it deployed an empty site over the CLI one. Build steps moved to `scripts/build-web.mjs`; `vercel.json` now has `buildCommand` and `outputDirectory: dist`, so Git builds and `npm run deploy:web` produce the same output. Git builds have no `.env.local`: `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_KEY` must be set in the Vercel project settings, or the site runs guest-only.

- 2026-10-09 — Landing page rebuilt from `Landing.dc.html` with the motion in `design/motion/MOTION.md` §9 (it had none before, and its layout had drifted). Now a web-only HTML/CSS component (`src/components/landing-page.web.tsx`; the app redirects to onboarding): wordmark wipe, typed "Un:changed → biased → masked → edited" with caret, rising text and buttons, six line-drawn sheets unfolding and drawing in behind the phone, Brand stamp landing on the phone, phone demo cycling Home → Library → You → Feed → Article with auto-scroll and tap ripples (screens are captures of the design boards in `public/lp/`, Paper and Ink), outlet marquee, scroll parallax, section reveals, "04 Your day" newspapers peeking up, auto-rotating source versions, desktop cursors, and reduced-motion fallbacks for all of it. Funding answer, contact email, privacy/terms and report links left out until they exist; Android button says "coming soon".

- 2026-10-09 — Fixed fonts on the live site: every app font (and a few icons) returned 404 on Vercel, because Expo puts them in `dist/assets/node_modules/` and the Vercel CLI never uploads `node_modules` folders. `npm run deploy:web` now renames that folder to `assets/pkg/` and rewrites the paths, so the site was showing system fonts until now.
